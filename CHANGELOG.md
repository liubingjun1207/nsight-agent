# Changelog

## 1.2.0.dev1 — unreleased

- Honor configured local env_vars and cwd in real connection checks, with explicit env overrides and clear rejection of unsupported remote configuration.
- Require both start and end boundaries, without an NVTX override, in first-second and first-ten-second model acceptance checks.

- Add fixed official Systems diagnostic rule discovery and a unified analyze tool; twenty tools total.
- Support six CUDA/GPU rules with exclusive time/NVTX scope, API-name filtering, sorting, complete findings before pagination and evidence exports.
- Validate installed rule parameters; bound gap/threshold/chunk inputs and retain official timing/utilization semantics.
- Preserve missing-data SKIPPED diagnostics that analyze --quiet hides in Systems 2025.6.3; reject unsupported schemas instead of claiming no findings.
- Add bilingual diagnostic guides, analysis skill routing, GPU-free contracts, direct CLI/STDIO integration and a real Codex evaluation case.
- Reuse the isolated report-copy/export cache and keep all existing tools compatible.

## 1.1.0 — 2026-10-13

- Add an owner-configured local Systems capture registry, bounded collection and report registration; no command/argument input through tool calls.
- Add a Linux source installer and actual Linux container reader/collection validation.
- Preserve the virtual-environment interpreter path during setup instead of resolving Linux symlinks to a base Python.
- Add recorded PyTorch eager NVTX/kernel association with explicit nesting and fusion limits.
- Add optional Compute report imports through five fixed metric groups, exact units, missing metrics and existing evidence exports.
- Expose eighteen MCP tools; retain all existing Systems reports and interfaces.
- Include the v1.0 configuration/cache/diagnostic fixes and extend usage, skill and scope documentation.

## 1.0.0 — 2026-10-12

- Close the fixed 18-report CUDA/NVTX scope through capability discovery and an allowlisted unified statistics tool; retain all v0.2 APIs.
- Add report-specific schemas, name/format parameters, launch and GPU-projection semantics, plus diagnostic error codes and recovery guidance.
- Package the analysis skill in wheels; add validated setup, actual configured-server checks and a Windows source-package installer.
- Add opt-in real Codex evaluations recording actual tool calls, numeric/range checks, exports and diagnostic behavior.
- Test source and installed wheels in CI; document separate numeric, model-flow and installation acceptance gates.
- Enter maintenance after the published acceptance record passes; new domains require an explicit scope revision.
